MOBILEARN BACKEND

Files:
- server.js: Node.js backend, no npm dependencies
- public/index.html: your original Mobilearn site connected to the backend
- public/admin.html: admin dashboard
- data.json: created automatically and stores users, withdrawals and chat messages

Run:
  node server.js

Open:
  http://localhost:3000
  http://localhost:3000/admin

Default admin:
  username: davis
  password: davis

IMPORTANT SECURITY:
1. Change the admin password before publishing. Set ADMIN_PASSWORD to a strong password before first run. The default is intentionally provided for local setup only.
2. HTTPS is required for public deployment. Use a reverse proxy or hosting platform with TLS.
3. Back up data.json regularly. It contains password hashes, not plaintext passwords.
4. This backend records withdrawal requests for manual review. It does NOT connect to Airtel Money or automatically send payouts.
5. User approval is enforced by the server. A pending user cannot log in.
6. The merchant code is a site setting/gate, not proof that a user paid. Verify activation payments separately before approving accounts.
7. Earnings are not generated by clicking tasks or ending a YouTube video. Do not promise rewards until you implement trusted server-side task verification and funding.

For Render:
- Build command: leave blank
- Start command: node server.js
- Add persistent disk mounted at /opt/render/project/src (or configure DATA_FILE support before deploying) to preserve data.json.
- Set ADMIN_PASSWORD in environment variables.
- Set PORT is provided automatically by Render.
